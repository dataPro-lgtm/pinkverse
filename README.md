# 粉红宇宙：真理大炮 · PINKVERSE — THE CANNON OF TRUTH

> 当所有人都掌握真理，谁还需要思考？

成人向黑色幽默物理弹射游戏。玩家操作一门“真理大炮”，在六个荒诞场景里拆除口号、揭穿双标、戳破流量泡沫。
游戏会记录你一路上的行为，最后一关的镜子会照出你变成了什么样的人。

所有角色都是虚构的网络人格原型。讽刺对象是行为、话术和权力结构（口号复读、双重标准、流量操纵、水军、带货、
绝对正确），不是任何民族或现实人物。游戏里的“事实核查卡”只针对虚构口号，结论一律是“尚无证据”，来源都是
虚构的泛指，不引用任何真实新闻。

## 怎么玩

- 按住屏幕拖动，瞄准线会实时显示炮弹轨迹；松手发射。手指离大炮越远，力度越大。
- 底部切换弹药。每关弹药有限，打完还有敌人就失败，可以重来，也可以“看广告复活”。
- 顶部三项指标：**思考**（核查、反问、发现矛盾）、**流量**（连击、爆炸、争吵）、**确信**（连胜、羞辱、忽视反证）。
  它们会改变台词、敌人血量、特殊弹药数量、广告、隐藏奖励、最终 BOSS 的形态和结局。

## 本地运行

需要 Node.js 18 或更高版本。

```sh
npm install
npm run dev        # 开发服务器，手机连同一 Wi-Fi 可用局域网地址访问
npm run build      # 类型检查并打包到 dist/
npm run preview    # 预览打包结果
```

调试参数：`?level=3` 直接进入第 3 关，`?reset` 清空存档，`?bot` 让测试机器人自动开炮。

## 技术说明

- TypeScript + Phaser 3.90 + Matter.js 物理，Vite 打包。Matter 使用固定 60Hz 步长。
- 所有图形在启动时用代码绘制，所有音乐和音效用 Web Audio API 现场合成：没有图片、音频或字体文件，
  没有第三方素材授权问题，运行时不依赖任何 CDN。
- 文字界面（计分、指标、弹药栏、面板、广告）是叠在画布上的 DOM，保证中文清晰、按钮可点。
- 竖屏优先，按 720×1280 设计并等比缩放；电脑上会显示成居中的竖屏画面。
- 存档用 localStorage：关卡解锁、最高分、金币、升级、彩蛋、结局、静音和本局指标。隐私模式下无法存档也能正常玩。
- 关卡数据在 `src/data/levels.ts`，台词和广告在 `src/data/lines.ts`，与逻辑分离。

```
src/
  main.ts            游戏配置与启动
  config.ts state.ts 常量、存档
  audio.ts           合成音乐与音效
  textures.ts bg.ts  程序化贴图、六个场景背景
  fx.ts ui.ts        粒子 / 漫画字 / 慢动作，DOM 界面
  data/              关卡、弹药、全部文案
  entities/          敌人、表情、道具、炮弹、大炮
  scenes/            启动、关卡、菜单、结局
  bot.ts             测试用自动玩家
tests/e2e.mjs        端到端测试（无头 Chrome，无额外依赖）
```

## 部署

`dist/` 是纯静态文件，可以放到任何静态托管。仓库自带 `.github/workflows/deploy.yml`：推送到 `main`
后由 GitHub Actions 打包并发布到 GitHub Pages（需要在仓库设置里把 Pages 来源设为 GitHub Actions）。
`vite.config.ts` 使用相对路径 `base: './'`，子路径部署无需改配置。
